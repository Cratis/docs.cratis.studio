# Cratis Studio documentation

This repository serves the published user documentation for [Cratis Studio](https://cratis.studio) at **[docs.cratis.studio](https://docs.cratis.studio)** through GitHub Pages.

The site is generated. Its source is written alongside Studio itself and published here automatically every time the documentation changes, onto the `gh-pages` branch. Do not edit the `gh-pages` branch by hand: the next publish replaces it.

- Read the documentation: [docs.cratis.studio](https://docs.cratis.studio)
- Try Studio: [cratis.studio](https://cratis.studio)
- Found something wrong or missing in the documentation? [Open an issue](https://github.com/Cratis/StudioIssues/issues/new).
